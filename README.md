# DSCR Estimator

A free, simple **DSCR Estimator** — calculate the Debt Service Coverage Ratio for a rental property or DSCR loan in seconds.

**Live site:** https://maniteja94.github.io/dscr-estimator/

## What it does

- Enter monthly rent, other income, taxes, insurance, HOA, maintenance, and vacancy/management %
- Enter loan amount, interest rate, and term
- Instantly get: **DSCR, annual NOI, monthly loan payment (P&I), annual debt service, and monthly cash flow**
- Verdict guide: 1.25+ strong (lender preferred), 1.00–1.24 borderline, below 1.00 weak

## Formula

```
DSCR = Net Operating Income / Annual Debt Service
```
